# 物色集 · Echoes of Things

> 「岁有其物，物有其容；情以物迁，辞以情发。」——《文心雕龙·物色》

输入一个意象（如「雨」），展示它在中国历代文学作品中的别称、情感承载、复合意象、电影转译，并以「生成链」和「意象—情感枢纽网」可视化意象间的关联。

**零 AI 内容。** 所有内容仅两个来源，界面逐条标注溯源徽标：
1. **内置精选库**（人工整理的 JSON，只收录真实可核实的出处）
2. **联网检索公开数据库**（原文照录 + 来源可点击，绝不改写）

## 在线预览

直接打开 `index.html` 即可使用（需联网以检索诗词库和维基百科）。

也可用任意静态服务器：
```bash
python -m http.server 8610
# 然后访问 http://127.0.0.1:8610
```

## 数据模型：四层生成链

依据《文心雕龙·物色》「物色之动，心亦摇焉」——外物触发情感，情感又反过来为外物命名、组合出新的意境：

1. **名（词汇层）**：同一事物的异名——「霖」「银竹」是雨的「名字」
2. **情（情感层）**：意象承载的情感——离愁、羁旅、乱世、喜雨
3. **境（复合意象层）**：意象与情境组合生成的新意境——「巴山夜雨 = 雨+夜+山 → 思归」
4. **译（跨媒介层）**：电影对意象的转译，注明情绪功能与古典溯源（承接 / 化用 / 反用）

## 数据来源

| 来源 | 用途 | 访问方式 |
|------|------|----------|
| 内置精选库 | 别称、情感、复合意象、电影、历代流变 | 本地 `js/data.js` |
| [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT） | 诗经、楚辞、论语、全唐诗、全宋词等 | raw.githubusercontent.com + 镜像回退 |
| [维基百科](https://zh.wikipedia.org) | 意象词条背景摘要 | REST API（origin=*） |
