# 物色集 · Echoes of Things

> 「岁有其物，物有其容；情以物迁，辞以情发。」——《文心雕龙·物色》

输入一个意象（如「雨」），展示它在中国历代文学作品中的别称、情感承载、复合意象、电影转译，并以「生成链」和「意象—情感枢纽网」可视化意象间的关联。

**内容声明。** 所有引文均为真实文献原句，界面逐条标注溯源徽标：
1. **内置精选库**「内置精选」（编者参考公开文献整理的 JSON，只收录真实可核实的出处；整理过程借助了工具辅助，非纯手工誊录）
2. **语料统计收录层**「语料收录」（程序对公开诗词库做词频 / 共现统计自动生成：例句为原文照录，情感与共现为计数结果；无 AI 生成内容）
3. **联网检索公开数据库**（原文照录 + 来源可点击，绝不改写）

## 在线预览

直接打开 `index.html` 即可使用（需联网以检索诗词库和维基百科）。

也可用任意静态服务器：
```bash
python -m http.server 8610
# 然后访问 http://127.0.0.1:8610
```

## 数据模型：四层生成链

依据《文心雕龙·物色》「物色之动，心亦摇焉」——外物触发情感，情感又反过来为外物命名、组合出新的意境：

1. **名（词汇层）**：同一事物的异名——「霖」「银竹」是雨的「名字」
2. **情（情感层）**：意象承载的情感——离愁、羁旅、乱世、喜雨
3. **境（复合意象层）**：意象与情境组合生成的新意境——「巴山夜雨 = 雨+夜+山 → 思归」
4. **译（跨媒介层）**：电影对意象的转译，注明情绪功能与古典溯源（承接 / 化用 / 反用）

## 两级数据分层

| 层级 | 徽标 | 条目数 | 内容 | 来源 |
|------|------|--------|------|------|
| 精选层 | 内置精选 | 31 | 五层完整数据 + 历代流变 | 编者整理 |
| 收录层 | 语料收录 | 800+ | 摘要 + 别称 + 例句 + 共现统计 | 程序统计生成 |

- **精选层**：首页展示、进入全局意象网，条条有文献出处。
- **收录层**：由 `scripts/build-data.mjs` 对 chinese-poetry 语料（诗经、楚辞、论语、唐诗三百首、全唐诗作样本、全宋词样本）做 n-gram 词频挖掘与共现统计生成。检索时本尊词与全部雅称联合命中（如搜「尺素」「青鸟」都能到达「书信」条）。首页不展示，搜索框输入即可查询。

重新生成收录层：
```bash
node scripts/build-data.mjs --top 800 --min-freq 8 --tang 0:58 --songci 0:22
# 可选参数：--wiki 启用维基摘要增强（不可达时自动回退统计描述）
# 语料缓存在 scripts/cache/（已 gitignore），重复运行增量加速
```

## 数据来源

| 来源 | 用途 | 访问方式 |
|------|------|----------|
| 内置精选库 | 别称、情感、复合意象、电影、历代流变 | 本地 `js/data.js` |
| [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT） | 诗经、楚辞、论语、全唐诗（58 卷）、全宋词（22 卷）等 | raw.githubusercontent.com + 镜像回退 |
| [维基百科](https://zh.wikipedia.org) | 意象词条背景摘要 | REST API（origin=*） |

注：chinese-poetry 仓库已将全唐诗/宋词按作者 ID 分卷（`poet.tang.0/1000/…json`），本项目已适配。

## 技术栈

纯前端单页应用，无构建工具，双击即用。
- 可视化：[ECharts 5](https://echarts.apache.org/)（CDN 动态加载）
- 字体：Noto Serif SC（系统回退思源宋体 / 宋体）
- 数据管线：Node.js 脚本（仅用于离线构建收录层，站点运行时不依赖 Node）
